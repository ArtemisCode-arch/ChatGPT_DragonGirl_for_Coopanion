# ChatGPT • 白银龙娘 形象包 for Coopanion

这个仓库用于为 Coopanion 添加白龙形象。形象包使用 Coopanion Figure API 2，提供 37 个表情和动作指令，以及互动音效。

## 安装

1. 下载 [白银龙娘形象包 v1.0.7（约 1.18 GB）](https://github.com/ArtemisCode-arch/ChatGPT_DragonGirl_for_Coopanion/releases/download/v1.0.7/ChatGPT_Silver_Dragon_Coopanion_v1.0.7.zip)。
2. 在 Coopanion 打开「设置 → 装扮 → 导入」，选择下载的 ZIP 并确认。
3. 在形象列表中选中「ChatGPT • 白银龙娘」。更新旧版时，在导入确认框中选择替换。

完整版适用 Coopanion v0.2.16 起的导入规则。超过 128 MiB 的包会在确认时显示体积提醒。

## v1.0.7 修复内容

- 重做左右走、跑、飞的起步、循环与收势，修复飞行缩放跳变和部分翼尖裁切。
- 重新衔接拎起、悬挂、松手与落地，覆盖移动中抓取及快速拎放。
- 重建待机与单次动作的 55 段过渡，清理重影、边缘串色和灰白杂色，并启用异步图集解码。

## v1.0.5 修复内容

- 走路、奔跑和飞行在准备、循环、收势切换前预读下一段的多页图集，单次动作结束前预读待机图集，减少等待解码造成的停顿。
- 逐帧处理 636 张无损 WebP 图集的 4,931 帧，清除 4,889 处轮廓外的孤立低 Alpha 杂点，校正 171,066 个低 Alpha 边缘像素的串色。通过相邻帧的位置判断保留淡入淡出的特效粒子。
- 沿用 v1.0.4 的原帧序、分辨率、音效和形象 ID。

## v1.0.4 修复内容

- 高清图集从保留的 720 × 720 原始高清动画重新生成，不放大旧版 320 像素图格。普通动作采用 512 × 512 图格，羽毛、灯泡、吐息、契约、印记、庆祝、比心、信任和宝藏等动作保留 720 × 720 图格。
- 所有新图集采用无损 WebP。导出后逐张解码核对 RGBA 像素；完全透明像素的 RGB 统一归零。缩放和局部插值采用预乘 Alpha，保留羽毛、发丝和发光效果的半透明细节。
- 延续已审阅的背景杂边清理区域，但从高清原图保留精细轮廓，不把旧版低分辨率边缘直接放大，不通过统一白色阈值删除亮色角色或特效。
- 播放器先完成离屏绘制，再提交完整画面。透明混合使用标准 source-over；图集尚未解码时保留上一完整帧，缩放不先清空可见画面。按实际图集页边界预取，减少跨页停顿。
- 图集改为每页最多 8 帧；缓存同时受页数和 128 MiB 解码像素预算约束。高 DPI 画布不再被旧版 640 像素上限限制。
- 右行走循环重新选取尾巴完整的原始步态，避免在稳定行走中反复接回尾巴收进身体的转身帧。保留原右行姿态和头饰方向。
- 走路和小跑使用原生 24 FPS 动作帧，移除整段强制补帧导致的发丝、裙边和尾巴重影；只在循环接缝使用短过渡。角色位置仍按宿主刷新率连续更新，脚步声按新帧序同步。

素材中的转身和身体遮挡属于原动作；本版修复的是稳定右行循环中的异常尾巴消失。没有更改人物造型或重新生成角色原画。

## 动作与互动

- 在动作列表选择「走路」「奔跑」「飞行」，也可以指定向左或向右。角色完成准备、移动和收势后回到待机；宿主移动指令也可以指定终点。
- 待机时，鼠标掠过左右翼尖、头顶呆毛或尾巴，会触发轻微摆动和回弹。点击头部、翅膀、尾巴或躯干可触发对应动作。
- 按住角色拖动时，角色围绕抓取点摆动；松手后下落，甩出时保留水平速度。落地点由宿主地板和活动范围决定。
- 招手、贴贴、比心、挥羽毛、翻绘本、玩掌机等单次动作在桌面上只播放一遍，然后回到待机。动作页预览沿用宿主的重复点播和停止操作。
